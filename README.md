# Shree.exe — Rajoshree Dhar's Digital World & Portfolio

**Creative direction:** Pixel Chic — retro pixel-game personality × luxury editorial sophistication × subtle futuristic details.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run typecheck
npm run build
npm run start
```

## Highlights
- **Canonical Interactive `Shree.exe` Pet:** Transparent sprites extracted directly from the canonical avatar (`public/sprites/`), with natural stepped blinking, tap/click dialogue bubbles, chapter guide menu, mood switcher, session-aware hint dismissal, minimise chip, and full `prefers-reduced-motion` support.
- **8 Editorial-Pixel Chapters:** Title Screen (`00`), The Player (`01`), The Inventory (`02`), The Laboratory (`03`), The Quests (`04`), The Soundtrack (`05`), The Side Quests (`06`), and The Next Level (`07`).
- **Dedicated Project Case Studies:** Static-friendly `/projects/[slug]` routes covering problem, approach, architecture, technical decisions, challenges, results, and lessons learned.
- **Keyboard & Accessibility First:** Skip link, focus-trapped full-screen Chapter Index (`M`), Shree.exe toggle (`S`), `Esc` to close overlays, and responsive mobile-first layouts.
- **Profiles Everywhere Needed:** LinkedIn and GitHub integrated into Top Navigation, Chapter Index, Projects, Case Studies, Contact (`CH.07`), and Footer.
